# 胖乖去广告

个人自用的安卓小工具，给「胖乖生活」（`com.qiekj.user`）去广告，与胖乖官方无关。不需要 root，不改胖乖本体，不上传任何数据。

## 给使用者：安装与设置

安装 `pgadskip.apk` 后打开「胖乖去广告」，按顶部清单完成以下步骤。从系统设置返回后会刷新 ✅/⬜ 状态，全部完成后折叠为「✅ 设置完成」，点击可展开。

1. **允许受限制的设置**：Android 13 及以上侧载安装后，点「打开应用详情」，再点右上角 **⋮ → 允许受限制的设置**。部分系统只有尝试开启无障碍、被拦截后才显示此项。Android 12 及以下无需这一步；Android 13 及以上以无障碍已开启作为完成标记。
2. **开启无障碍服务**：点「打开无障碍设置」，找到「胖乖去广告」并开启。它只在胖乖里识别页面、跳过广告和处理付款推广。
3. **开启网络拦截**：点「开启网络拦截」，在系统 VPN 授权框确认。本地 VPN 只处理胖乖的 DNS 查询：拦截名单中的域名，其余查询转给 DNS 服务器；不上传页面、日志等数据。运行后状态栏通常有钥匙图标。手机同时只能运行一个 VPN，与 Clash 等会冲突；清单以实际运行状态为准，勾选但未运行时不会显示完成。
4. **省电策略设为「无限制」**：点「打开应用详情」，选择 **省电策略 → 无限制**；小米还要打开自启动。完成状态依据系统的电池优化豁免接口判断，厂商页面的名称和检测结果可能不同，自启动需自行确认。本工具不申请直接忽略电池优化的权限。

付款页面会自动关闭「领取3天胖乖会员」开关、点「放弃优惠」，取消勾选会跳到微博/淘宝的推广；点「去支付」后被带进推广网页时会自动返回，之后再点一次「去支付」。这些行为都有独立开关，可按需要关闭。

「记录界面结构」默认关闭，仅调试用。开启后会把胖乖页面文字记到本机日志，可能包含手机号、订单号、地址；不要随意分享日志。升级会保留原有开关选择，旧用户请检查此项是否开启。

## 怎么做到的

两层配合：

1. **网络拦截**（`DnsVpnService`）：一个只管胖乖的本地 VPN。只有胖乖的 DNS 查询会进来，名单上的广告、直播域名直接回「不存在」，其余照常转发。别的 app 的流量不经过它。
2. **无障碍服务**（`AdSkipService` + `FeedCover`）：
   - 自动点开屏广告的「跳过」、关掉插屏和广告弹窗；
   - 网络拦不掉的部分（福利助手、商城入口、推广图标等），盖一块和页面同色的挡板抹掉。

规则按广告的共同特征来认（「跳过」字样、广告 SDK 的类名和控件 id），不绑胖乖的具体版本。

## 名单（改了不用重装）

APK 自带两份名单，首次运行自动写到以下位置，无需手动推送。仓库根目录的 `blocklist.txt`、`hide.txt` 是唯一内置来源，构建时才复制到暂存目录的 `res/raw/`。

| 文件 | 手机上的位置 | 作用 |
|---|---|---|
| `blocklist.txt` | `/sdcard/Android/data/com.zz.pgadskip/files/blocklist.txt` | 网络拦截的域名，一行一个，`a.com` 同时拦子域名 |
| `hide.txt` | `/sdcard/Android/data/com.zz.pgadskip/files/hide.txt` | 界面上要抹掉的东西：图标名 / `卡片:标题` / `id:控件名` |

升级时按文件完整字节的 SHA-256 比较：手机文件与上次写出的内置名单完全一致才自动更新；手动修改过的保留。旧版没有哈希记录，已有文件也保留；若恰好与新版内置内容一致，则建立后续升级基线。设置页的「恢复内置名单」会覆盖两份文件及自定义修改，并立即重新加载。

开发调试也可以手动修改手机文件，使用到名单时会在 5 秒检查间隔内重新加载，不用重装。例如：

```bash
adb push blocklist.txt /sdcard/Android/data/com.zz.pgadskip/files/blocklist.txt
```

**不能拦的域名**：`youzan.com`、`youzanyun.com`（拦了胖乖会崩溃）、`qiekj.com` 整个（胖乖自己的接口）、微信 / 支付宝的付款域名。

## 构建

不用 Gradle，`build.ps1` 直接调 aapt2 → javac → d8 → zipalign → apksigner。需要：

- JDK 17
- Android build-tools 35.0.1、platform android-35

路径写在 `build.ps1` 开头（默认 `E:\DevTools`）。源码先复制到 `E:\DevTools\pgadskip-stage`，避免 aapt2 不识别中文路径。每次构建从根目录名单生成 raw 资源和 SHA-256 资源，仓库内不保留名单副本。

签名配置和密钥库都必须放在仓库外。先在普通文本编辑器中创建 UTF-8 文件 `E:\DevTools\pgadskip-signing.properties`，格式如下（将占位内容替换为实际口令，不要提交此文件）：

```properties
storeFile=E:\DevTools\pgadskip.jks
storePassword=<密钥库口令>
keyAlias=pgadskip
keyPassword=<私钥口令>
```

这是简单的 `key=value` 格式，Windows 路径反斜杠无需转义，口令不加引号，等号后的内容原样读取。`storeFile` 使用绝对路径。继续使用现有 JKS 和签名别名才能覆盖升级，改口令不改变签名身份。脚本不自动生成密钥，配置或密钥库缺失时会直接报错。口令仅在签名时通过环境变量交给 apksigner，不出现在命令行参数中。

```powershell
.\build.ps1

# 可用参数覆盖配置位置，也可设置 PGADSKIP_SIGNING_CONFIG 环境变量；参数优先。
.\build.ps1 -SigningConfig E:\DevTools\my-signing.properties
```

构建后会校验签名，产物为 `build\pgadskip.apk`。把这个 APK 发给使用者即可；不要分发密钥库或签名配置。真机安装和验收另行手动完成。
## 排查

运行日志在手机 `/sdcard/Android/data/com.zz.pgadskip/files/log.txt`，只存在本地：

- `DNS BLOCK/allow 域名`：胖乖连了哪些地方；
- `CLICK ...`：点了什么；
- `cover show/hide`：挡板位置；
- 记录模式下还有界面结构 `DUMP`（默认关闭，仅调试用，可能包含个人信息）。

## 已知限制

- 开着网络拦截走付款流程还没完整测过。付款相关域名都没拦，如果卡住，先在 app 里关掉「网络拦截」。
- 手机同时只能开一个 VPN。开 Clash 时它会自动让开，胖乖下次打开时再补上。
- 小米手机要把本 app 的省电策略设为「无限制」，否则可能被后台清掉。
- 胖乖在系统深色模式下仍为浅色，挡板保持原有浅色，并在 Android 10 及以上禁用强制深色；本工具的设置页随系统深浅主题切换。
